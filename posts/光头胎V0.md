**原装胎能跑完一圈之后，像我前几篇说的一样没有负压转弯只能靠摩擦力，为了提速蛊惑刘子赫把光头胎换来了，这一版是换了光头胎的第一版，在这写写关于对光头胎理解**

**正常胎的表面有一层氧化层，对准灯光可以看到是反光的，光头胎不光磨掉了花纹，还把表面的氧化层磨掉了。像橡胶一样更粘，摩擦力更大，但是非常容易沾灰尘，赛道需要用粘毛器**

**胎表面本身是光的，如果沾了灰尘就会像胎表面沾了小滚珠一样，比原装胎更容易打滑**

**胎表面如果不做处理隔段时间就会再次氧化（这次比赛我们的备赛周期很短，正常比赛周期应该是要用特殊方法处理一下让他没那么容易氧化，我也不知道怎么处理不过咸鱼上有专门干这个的）**

这一版的速度是：直道 850，入弯 800，出弯 650。上一版原装胎是 700 / 450 / 550，入弯速度几乎翻倍——因为光头胎抓得住，敢带着速度进弯。

差速限幅也改成了两档：

```c


if (wan_flag == 0)              /* 直道 */
{
    if (turn_out >  400) turn_out =  400;
    if (turn_out < -400) turn_out = -400;
}
else                            /* 弯道 */
{
    if (turn_out >  2500) turn_out =  2500;
    if (turn_out < -2500) turn_out = -2500;
}
```
直道只给 ±400，是因为直道上电感噪声一小点，差速就抖，车头左右摆，看着像"发飘"。弯道才放开到 2500。

环岛这一版是五个状态：找口 → 打角预备 → 入环打角 → 环内循迹 → 出环打角 → 回正。

出环那段现在看挺暴力：

turn_out = -1700;   /* 向左打弯拉入直道！！！ */
