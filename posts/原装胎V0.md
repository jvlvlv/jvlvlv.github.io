上一版（kp20 编码 - 入弯减速 - 环岛）已经能跑完全程，环岛也能进。但它有两个毛病一直记着。

一个是减速总慢半拍。判断“在弯里”靠的是左右横电感的差值，等差值变大，车头已经进弯了，这时候再减只能算刹车，不算减速。

另一个是环岛识别太脆。上一版直接拿原始 ADC 卡门限，右横 > 730、左横 < 450 这种。换块电池、电感高度差 2 mm，数值全变。

于是有了这一版。

先说减速。

横电感是“现在偏了多少”，竖电感是“前面有没有东西”。车还没进弯，弯道外侧的竖电感已经开始涨了，这是一个白送的预判信号，不用加任何硬件。

做法是两段折线：低于直道门限不减速，高于弯道门限减到入弯速度，中间线性插值。

```c


#define L_STRAIGHT_TH  135      /* 左竖：直道门限 */
#define L_CURVE_TH     380      /* 左竖：弯道门限 */
#define R_STRAIGHT_TH  35       /* 右竖：直道门限 */
#define R_CURVE_TH     110      /* 右竖：弯道门限 */

if (Avg_Adc[1] > L_STRAIGHT_TH)
{
    if (Avg_Adc[1] >= L_CURVE_TH)
        base_speed_L = ENTER_TURN_SPEED;                    /* 450：确定在弯里 */
    else
    {
        ratio = (float)(Avg_Adc[1] - L_STRAIGHT_TH) / (L_CURVE_TH - L_STRAIGHT_TH);
        if (ratio > 1.0f) ratio = 1.0f;
        base_speed_L = target_speed_L - (int16)((target_speed_L - ENTER_TURN_SPEED) * ratio);
    }
}
else base_speed_L = target_speed_L;                          /* 700：直道全速 */

/* 左右各算一次，哪边更急就听哪边 */
base_speed = (base_speed_L < base_speed_R) ? base_speed_L : base_speed_R;
```
出弯另算一笔账：wan_flag 从 1 掉到 0 的那一刻，开一个 200 拍（1 秒）倒计时，这 1 秒压到 550。

```c


if (last_wan_flag == 1 && wan_flag == 0) exit_turn_cnt = EXIT_TURN_SLOW_TIME;
last_wan_flag = wan_flag;

if (exit_turn_cnt > 0) { exit_turn_cnt--; base_speed = SLOW_SPEED_L; }  /* 550 */
```
左右门限差得很远，135/380 对 35/110。不是笔误，两个电感的圈数、离地高度、放大倍数都不一样，各自的数值本来就不在一个量级。所以这一步我用的是原始值，折线本来就是在原始域里标出来的，归一化反而会把这种个体差异抹平。


再说环岛。

上一版是这么判入环的：

```c


if (Avg_Adc[3] > 730 && Avg_Adc[2] > 30 && Avg_Adc[0] < 450)
```
730 是某一天、某块电池、某个离地高度下的 730，换一天就没了。

这一版改用归一化之后的 0–100。环岛入口的磁场其实特别干净：两个横电感同时接近满值，两个竖电感同时接近零，因为车头正对着一圈线圈的缺口，横向的线在你左右两边，纵向的线暂时看不见。

```c


if (Adc_LEFT1_Value > 92.0f && Adc_RIGHT2_Value > 92.0f &&
    Adc_LEFT2_Value <  5.0f && Adc_RIGHT1_Value <  5.0f)
{
    ring_timer++;
    if (ring_timer > 3) { ring_state = 1; ring_timer = 0; }   /* 20 ms 消抖 */
}
else ring_timer = 0;
```
这一步的价值不是更准，是可移植。以后换电感、换高度，只要重标一次归一化区间，92 / 92 / 5 / 5 大概率还能用；上一版那种原始值方案，每次都得重新摸一遍。

环内上一版是一段固定偏置 out * 0.5 + 800，两个毛病都出现过：偏置大了往内圈扎，偏置小了被直道拉出去。这一版拆成两段：

```c


else if (ring_state == 2)
{
    ring_timer++;
    base_speed = ENTER_TURN_SPEED;

    if (ring_timer < 200)      /* 前 1 秒：PD 权重降到 0.3，加 -450 底油 */
        turn_out = (int16)(Servo_ppd_struct.out * 0.3) - 450;
    else                       /* 1 秒后：已经在环里，纯 PD 循迹 */
        turn_out = (int16)(Servo_ppd_struct.out;
}
```
思路是：刚进环的第一秒别信电感，四个电感都在剧烈变化，PD 的输出没意义，给一个固定底油把车“按”在环里；一秒后车身姿态稳了，再把控制权还给循迹。

出环判据是跑满 1.5 秒 + 两个横电感重新变大，3 秒兜底。

```c


if (ring_timer > 300)                                   /* 1.5 s */
{
    if (Adc_LEFT1_Value > 60.0f && Adc_RIGHT2_Value > 60.0f)
    { ring_state = 3; ring_timer = 0; }
}
if (ring_timer > 600) ring_state = 0;                   /* 3 s 兜底 */
```
结果。

入弯明显早了，不用等车头歪了才减速，出弯也不甩了。代价是直道速度被我从 1000 压到 700，圈速估计慢了一点，但当时更怕它飞出去。

代码里还留着几处债，顺便记一下：

注释说“核心公式 out*0.3 - 600”，代码里是 -450。注释比代码老，我一直没改。
base_speed_R 那里我手误写成了 target_speed_L。因为左右都设成 700，现在完全没影响；哪天用按键把左右调成不一样，右轮减速就会算错。
所谓“双 PD”其实只有一个 P，kp2 和 kd 都是 0，结构留着没用。
